# Groupfitness by Katja

Landingpage für wöchentliche Zumba® Kurse in Flaach (ZH).

## Features

- Wochenplan mit Anmeldung & Kalender-Export (.ics)
- Preise & Abos mit Zahlungsflow (Bargeld & TWINT)
- Bring a Friend Aktion
- Events & Specials
- Kontaktformular (via WhatsApp)
- Vollständig responsiv (Mobile-first)

## Tech Stack

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Framer Motion

## Lokale Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
